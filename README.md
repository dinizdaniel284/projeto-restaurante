# 🍔 DevBurger - Sistema de Pedidos Online

Este é um projeto de **Landing Page para Restaurantes** focado em conversão e facilidade de uso. Desenvolvido para oferecer uma experiência de pedido rápida via WhatsApp, eliminando a necessidade de apps de terceiros e taxas abusivas.

## 🚀 Funcionalidades
- **Cardápio Dinâmico:** Interface moderna e intuitiva.
- **Carrinho de Compras:** Sistema funcional que soma valores e gerencia itens.
- **Integração WhatsApp:** Gera o pedido detalhado e envia direto para o estabelecimento.
- **Design Responsivo:** Otimizado para smartphones e tablets.

## 🛠️ Tecnologias Utilizadas
- HTML5 / CSS3 (Flexbox & Grid)
- JavaScript (Manipulação de DOM e Lógica de Carrinho)
- Google Fonts & Font Awesome

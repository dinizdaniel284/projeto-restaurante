---

### 🚀 Diferenciais do Projeto
- [x] **Cardápio Inteligente:** Interface intuitiva que facilita a escolha do cliente.
- [x] **Carrinho em Tempo Real:** Soma automática de valores e gerenciamento de itens.
- [x] **Checkout Automatizado:** Gera a mensagem formatada para o fechamento via WhatsApp.
- [x] **Mobile First:** Totalmente otimizado para pedidos via smartphone.
